# Casa Belgica — Sortir du squat / Leave the Squat

Site statique de la campagne Casa Belgica : coopérative de logement de transition en création, portée par Ballal ASBL (Molenbeek).

- `fr.html` — version française
- `index.html` — version anglaise
- `ANALYSE-GRAPHIQUE.md` — analyse graphique du site précédent et choix de cette version

Deux fichiers HTML autonomes, sans build : à déposer tels quels sur Vercel, Netlify ou GitHub Pages. Polices chargées depuis Google Fonts (Bricolage Grotesque, Instrument Sans).

Palette : vert nuit `#13251A`, vert `#1F4A35`, or `#E3C362`, crème `#F3F1EA` — la même que le dossier imprimé.
